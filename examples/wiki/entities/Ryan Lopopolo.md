# Ryan Lopopolo

Member of Technical Staff at [[entities/OpenAI]]. Led a small engineering team running the "zero manually-written code" experiment, using [[entities/Codex]] to build an internal product from an empty git repository over ~5 months. Author of the [[summaries/2026-02-11-harness-engineering-en]] post on the experience.

The post's acknowledgements call out Victor Zhu and Zach Brock as contributors, and the broader team that built the product.

## Selected quotations (from the post)

> "Humans steer. Agents execute."

> "When everything is 'important,' nothing is."

> "When documentation falls short, we promote the rule into code."

> "Corrections are cheap, and waiting is expensive."

## Representative ideas

- The job of a software engineer in an agent-first world is to **design environments, specify intent, and build feedback loops** — not to write code.
- **Anything the agent cannot access in-context effectively doesn't exist.** Knowledge in Google Docs, Slack, or people's heads is invisible to the system.
- **Discipline doesn't disappear; it migrates from the code to the scaffolding** — tools, abstractions, linters, observability.
